Submit one ZIP file named `MBAB5P19_Fall2026_VC-Assign_Group#` (replace `#` with the group number). Each deliverable is a separate file:

4. The Vibe Coded Application: user instructions, full code as `.txt` and `.html` (20 points)
5. Overall packaging and professionalism (10 points)

Text format: MS Word, 1 inch margins, single spacing, 12-point Times New Roman.
